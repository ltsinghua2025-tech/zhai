# 公文格式执行依据

依据用户提供的 GB/T 9704—2012《党政机关公文格式》，2026-09-15 提炼。

## 0.23 离线排版边界

- `docx_to_gongwen` 不补齐原文没有的主送、落款或版记。`recipientMode=auto` 保守识别，`none` 不添加主送；不能只凭冒号或首段位置判断角色。
- `signatureMode=preserve` 为默认，保留原落款布局。仅用户明确无章单一机关时用 `unsigned`：补足正文/附件说明与署名之间一行间隔，按署名、日期长度安排相对位置；不修改日期内容。没有印章图片不代表不盖章，联合/浮动签章不套该规则。
- `formatTables` 新默认 false；true 仅调整安全普通表格的字体名，不改字号、行距、列宽、行高、合并结构。定位/版记/固定行高表格保留。
- 已有页脚与PAGE等域完整保留，不重复添加；无页脚的普通单节文档可生成奇偶页码。复杂首页页码、混合页脚仅提示核对。
- 必要空白、图片/域/分页/分节/书签段落受保护；不自动改编号或纠正事实内容。自动编号、链接等复杂段落保留并提示；长附件不强制整组同页。
- 多节、横向/分栏、已有红头、浮动对象/修订/内容控件本版保留原版式，不宣称完成重排。组合流程先排正文再套红，不反过来强行格式化模板。
- “排版提示”必须反馈用户；结构检查不等于视觉验收。按版本锁定的旧工作流需重新测试，不静默绕过锁定。

优先调用已发布的 apply_redhead；公文正文排版调用 docx_to_gongwen。单位现有模板优先；普通公文、信函、命令和纪要有不同规则，不将模板差异宣称为国标。

- 5.1–5.2：A4 210×297mm，上白边37±1mm，左白边28±1mm，版心156×225mm。一般22行、每行28字，可按实际调整。一般3号仿宋、黑色。
- 7.2：红色发文机关标志居中，推荐小标宋，上边缘距版心上边缘35mm。发文字号下空二行，年份用六角括号，不补零；普通下行文居中。红色单分隔线位于发文字号下4mm，与版心等宽。
- 7.3：标题一般2号小标宋，红线下空二行，居中并按词义断行。主送机关标题下空一行、顶格。首页必须有正文。正文3号仿宋、首行空二字；一级黑体、二级楷体、三级四级仿宋。保留原文内容与用户指定加粗。
- 附件说明正文下空一行，名称回行对齐；附件另面、在版记前，页码连续。印章及签发人不能虚构。成文日期与印发日期分别处理。
- 7.4：版记位于末页。首末粗线推荐0.35mm，中间细线0.25mm，均与版心等宽；末线贴合末页版心下边缘。印发机关和日期一般4号仿宋，左右各空一字。印发机关可为单位办公室，与发文机关不是同一字段。日期用阿拉伯数字，不补零，后加“印发”。
- 7.5：页码4号半角宋体数字，两侧一字线，距版心下边缘7mm；奇数右空一字、偶数左空一字。空白页及特殊版记页按标准处理。
- 10.1：信函式样使用上下红色双线，长170mm。首页不显示页码，版记不加印发机关、印发日期和分隔线。用户要求的双线模板加普通版记属于自定义样式，不能声称严格国标信函。

未给单位用“中共珠海市xxx”，未给印发日期用“202x年x月x日印发”；最终答复提示待补。officeName 仅按用户要求追加，已含后缀不重复。字体不足必须报告原字体与替换状态；只能检测到缺失时应注明实际替代字体尚未确认。

验收：重新打开DOCX、逐页渲染，核对正文/表格/图片完整、文头不重复、无模板教学文字、末页版记只出现一次、页码正确、原件哈希不变。多节横向正文及无法识别边界的模板先报告具体限制，不静默丢弃。
