麒麟安装步骤

  1. 完整解压 ZIP，打开含有 安装.sh 的文件夹。
  2. 在该文件夹中打开终端，运行 bash 安装.sh。
  3. 安装完成后，从应用菜单打开 zhai。天翼 API 已配置，可直接开始使用。
